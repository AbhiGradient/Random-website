🚗 Random-Website

This is a frontend-only eCommerce practice project showcasing car modification parts.  
It was created as my first beginner project using HTML, CSS, and JavaScript.  
The main goal was to understand how real-world websites are structured, how multiple pages are linked, and how basic styling and interactivity work.  

⚠️ Since this was my first project, there will be flaws — but that’s part of the learning journey!

---

📌 Project Purpose
- Learn HTML page structure  
- Practice CSS styling and layouts  
- Understand JavaScript basics  
- Explore Git, GitHub, and GitHub Pages  
- Build confidence by creating a multi-page website  

---

✨ Features
- Multi-page website navigation  
- Home page (index.html)  
- Car-specific pages (example: WRX)  
- Basic responsive layout  
- Clean folder structure  

---

🛠️ Technologies Used
- HTML5  
- CSS3  
- JavaScript  
- Git & GitHub  
- GitHub Pages (for hosting)

💻 How to Run Locally
1. Download or clone the repository  
   
   git clone:
   https://github.com/AbhiGradient/Random-website/
   
3. Open the folder  
4. Double-click index.html  
5. The website will open in your browser
